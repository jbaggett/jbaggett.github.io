Scatterplot Editor

Build and reshape a scatterplot and watch the least-squares regression line respond in real time. Grab an ordinary point and pull it far out in x — the line chases it (high leverage & influence). Pull a point far in y near the middle of the x range — it barely moves the line (an outlier, high residual but low leverage).

Mouse: drag a point to move it, click empty space to add one, click a point to remove it.

Keyboard (no dragging needed): press Tab to focus a point, then use the arrow keys to move it (hold Shift for larger steps) and Delete or Enter to remove it. To add a point, type an x and y value in the "Add a point" boxes below the chart and press Add point.
