Two-Proportion z-Test

Compare the proportions of two independent groups (p1 − p2), using a z-statistic and the standard normal distribution.

  • Load data from the Datasets, Edit Data (a group column and an outcome column), or Open File tab, or use Enter Summary to type the successes and n for each group.
  • Grouping / outcome selectors and Count as success let you choose the columns and the success category when loading raw data. Swap Group 1 ↔ Group 2 flips which group is subtracted.
  • Alternative (Ha): click the toggle to cycle ≠, <, > for a two-sided or one-sided test.
  • Null value: standard mode tests p1 − p2 = 0. Turn on Expert mode (settings gear) to make the null difference editable.
  • Conditions checkpoint reminds you to check the success/failure counts in each group.
  • Results — the z-statistic, p-value, confidence interval, and plot — appear automatically as you change inputs. There is no Compute button.
