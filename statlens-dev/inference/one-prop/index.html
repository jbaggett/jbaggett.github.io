One-Proportion z-Test

Test whether a population proportion p differs from a hypothesized value, using a z-statistic and the standard normal distribution.

  • Load data from the Datasets, Edit Data (one value per line), or Open File tab, or use Enter Summary to type the number of successes and n.
  • Count as success: when the data has categories, pick which one counts as a success.
  • Null value: type the hypothesized proportion p0 in the H0 row (defaults to 0.5).
  • Alternative (Ha): click the toggle to cycle ≠, <, > for a two-sided or one-sided test.
  • Conditions checkpoint checks the success/failure counts (np0 and n(1−p0) ≥ 10).
  • Confidence level sets the matching interval (default 0.95).
  • Results — the z-statistic, p-value, confidence interval, and plot — appear automatically as you change inputs. There is no Compute button.
