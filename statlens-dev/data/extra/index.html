Extra Datasets

These datasets were sent in by instructors and are hosted on StatLens. Because the dataset menus inside the tools are curated for the course, contributed datasets are reached by link instead:

  • Click any Open in… link to load the dataset in that tool.
  • Use Copy link to get a URL you can paste into a slide, an LMS page, or an assignment. Once it's open, the tool's own Share button turns that link into a QR code.

To contribute one, see For instructors. Emailing a spreadsheet is enough — no accounts, no file hosting, no GitHub.
