One-Sample t-Test

Test whether a population mean μ differs from a hypothesized value, using a t-statistic and the t-distribution.

  • Load data from the Datasets, Edit Data (paste), or Open File tab, or use Enter Summary to type the sample mean, SD, and n directly.
  • Null value: type the hypothesized mean μ0 in the H0 row (defaults to 0).
  • Alternative (Ha): click the toggle to cycle ≠, <, > for a two-sided or one-sided test.
  • Conditions checkpoint reminds you to check the sample size and shape before trusting the result.
  • Confidence level sets the matching interval (default 0.95).
  • Results — t, df, p-value, the confidence interval, and the plot — appear automatically as you change inputs. There is no Compute button.
