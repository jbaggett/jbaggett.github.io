Data Workbench (prototype)

A prototype for exploring data in one place, the way tools like Jamovi work — but routed into StatLens's guided tools.

  • Load a bundled dataset, or paste your own CSV/TSV.
  • Sort any column with the ↕ button in its header.
  • Select a column by clicking its header (up to two).
  • See summary stats and an automatic chart for what you selected.
  • Use Suggested analysis to open the matching StatLens tool with the data loaded.
